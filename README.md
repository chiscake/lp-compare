# LP-методы для задач распределения ресурсов: симплекс, внутренняя точка, DLN

Подготовка эксперимента и статьи для VII МНПК «Цифровая трансформация – шаг в будущее» (ЭФ БГУ, 2026):
сравнение табличного симплекса (правила Данцига и Бланда), прямо-двойственного метода внутренней точки
(Мехротра) и градиентного спуска на диагональной линейной сети (Wang, Ghosal, Mazumder, arXiv:2310.02535).

Текущее состояние: теория и план работ — [`docs/theory-and-plan.md`](docs/theory-and-plan.md).
Код генератора, решателей (C#, Native AOT) и анализа появится на следующих этапах плана.
